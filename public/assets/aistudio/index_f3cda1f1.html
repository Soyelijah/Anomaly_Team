💡 ¿Cómo funciona la lectura automática de datos?

El sitio web oficial de Smash MU publica la tabla de posiciones global en un punto de acceso (API) público. Este portal realiza una petición directa a esa URL, extrae todos los jugadores del servidor y los filtra instantáneamente usando el nombre de tu clan.

Código Serverless para evitar bloqueos de seguridad (CORS) opcional en Vercel:
// Archivo en tu proyecto: api/smash-sync.js
export default async function handler(req, res) {
    const response = await fetch('https://smash-mu-nu.vercel.app/api/rankings');
    const data = await response.json();
    
    // Filtrar solo los jugadores pertenecientes a TU CLAN
    const myClanName = "LEGION_SMASH"; 
    const clanMembers = data.filter(p => p.guild && p.guild.toLowerCase() === myClanName.toLowerCase());

    res.setHeader('Access-Control-Allow-Origin', '*');
    return res.status(200).json(clanMembers);
}
